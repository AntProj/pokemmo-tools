# Screenshots

These images are referenced by the top-level [`README.md`](../../README.md). Save each
screenshot into this folder using the exact filename below (PNG). Dark-mode, ~1900px-wide
captures look best.

| Filename | View to capture |
| --- | --- |
| `pokedex.png` | **Hero** — the Pokédex grid (the home tab), e.g. Bulbasaur → Caterpie. |
| `pokedex-filters.png` | Pokédex with advanced filters open (a move or type filter applied, results narrowed). |
| `locations.png` | Locations — the region list (e.g. Kanto: Pallet Town, Route 1, …). |
| `locations-detail.png` | Locations — a single location opened, showing its Pokémon cards (e.g. Route 4). |
| `maps-zone.png` | Maps — an interactive zone with trainer markers (e.g. Route 222). |
| `damage-calc.png` | Damage Calc — the calculator with the field panel. |
| `team-builder.png` | Team Builder — the analysis view (defensive weaknesses / offensive coverage / speed tiers). |
| `breeding.png` | Breeding — the planner with the recipe & cost breakdown. |
| `gym-prep.png` | Gym & E4 Prep — the trainer card grid. |

After the files are in place the README gallery renders automatically — no code changes needed.
